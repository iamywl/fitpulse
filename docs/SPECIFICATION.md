# FitPulse 서비스 기능명세서 (PRD & Technical Specification)

- **문서 버전**: v1.3.0 (토스 디자인 시스템 TDS Mobile & Phase 1 킬러 기능 완성)
- **작성 일자**: 2026-09-10
- **디자인 철학**: **"당연한 것을 더 쉽고 명확하게"** (Toss Design System Mobile)
- **대상 플랫폼**: Web MVP (모바일 390px 뷰포트 & 데스크톱 반응형) -> 향후 React Native 모바일 앱

---

## 1. 프로젝트 배경 및 기획 의도

### 1.1 핵심 문제의식 (Pain Points)
1. **훈련 몰입 방해와 느린 기입**: 운동 세트 간 쉴 때 불필요한 depth를 거치지 않고 무게와 횟수를 원터치로 빠르게 기록할 수 있어야 함.
2. **운동 후 공유의 번거로움**: 인스타그램 스토리에 '오운완' 인증을 올릴 때 지저분한 UI 캡처 대신 1080×1920 규격의 깔끔한 브랜드 카드가 필요함.
3. **바벨 원판 암산 피로**: 목표 중량 달성을 위해 20kg 봉 무게를 제하고 양쪽에 꽂아야 할 플레이트를 즉시 시각적으로 확인하고 싶음.
4. **휴식 시간 오버**: 세트 간 스마트폰의 다른 앱을 보더라도 시스템 푸시 알림과 진동으로 제때 다음 세트를 시작해야 함.
5. **객관적 점진적 과부하 가이드 부재**: 오늘 컨디션(RPE)과 지난 세션 기록을 바탕으로 다음 세트에 도전해야 할 무게를 스마트하게 추천받아야 함.

## 2. 디자인 시스템: 토스 디자인 시스템 (TDS Mobile)

FitPulse는 토스(Toss) 특유의 극도로 정갈하고 직관적인 모바일 디자인 원칙을 계승합니다.

| 색상 명칭 | HEX / RGBA 토큰 | 용도 및 시각적 대비 (Accessibility) |
|---|---|---|
| **Toss Signature Blue** | `#3182F6` | 토스 시그니처 블루. 핵심 액션(CTA), 선택 탭, 주요 지표 강조. WCAG AAA 기준 부합. |
| **Toss Blue Weak (Light/Dark)** | `#E8F3FF` / `rgba(49, 130, 246, 0.16)` | 버튼 및 뱃지 소프트 틴트 배경. |
| **OLED Deep Charcoal** | `#101012` | 다크 모드 베이스 배경. 배터리 소모 절감 및 눈의 피로 최소화. |
| **Toss Surface Card** | `#1C1C1E` (Dark) / `#FFFFFF` (Light) | 메인 콘텐츠 카드 및 모달 서페이스. |
| **Toss Hairline Border** | `#2C2C2E` (Dark) / `#E5E8EB` (Light) | 정밀한 1px 헤어라인 경계선. |
| **Semantic Success (Teal/Green)** | `#00BFA5` / `#00C73C` | 목표 달성, 점진적 과부하 성공, 히트맵 잔디. |
| **Semantic Danger (Red)** | `#F04452` | 한계 피로 도달, 디로딩 알림. |
| **Semantic Warning (Yellow)** | `#FF9F00` | 주의 구간, 고중량 RPE 경고. |

## 3. 핵심 기능 요구사항 명세 (Functional Specifications)

### [FR-01] 오늘 워크아웃 HUD & 0-Click 루틴 진입 (Today's Active Workout Hero)
- 앱 접속 즉시 당일 요일 루틴과 첫 번째 운동의 세트 기입기가 자동으로 활성화.
- 실시간 세션 진행률 프로그레스 바 제공.
- "오운완 카드 다운로드", "원판 계산기", "커스텀 종목 추가" 원터치 퀵 액션 제공.

### [FR-02] 오운완 고해상도 인스타그램 스토리 Canvas 다운로드 (WorkoutCardCanvasService)
- 1080×1920 (9:16) 규격 2D Canvas 자동 렌더링.
- 딥 다크 앰비언트 글로우, 총 볼륨 메가 카드, 3열 메트릭(완주 종목/세트/RPE), 완주 종목 리스트, TDS 공식 슬로건 워터마크 탑재.
- 브라우저 무지연 1클릭 PNG 다운로드 지원.

### [FR-03] 덤벨/머신/바벨 커스텀 운동 종목 자유 등록 (ExerciseLibraryService)
- 종목명, 부위(가슴/등/하체/어깨/팔/코어), 장비(바벨/덤벨/머신/케이블/맨몸), 타겟 근육 직접 설정.
- LocalStorage 영속화 및 기본 35개 마스터 라이브러리와 원활한 통합.

### [FR-04] 백그라운드 웹 푸시 알림 & 햅틱 진동 연동 (WebNotificationService)
- 브라우저 비활성화/백그라운드 전환 상태에서도 Web Notification API를 통한 시스템 알림 발송.
- Navigator Vibration API 기반 모바일 햅틱 진동 피드백 (`[250, 120, 250, 120, 500]ms`).
- 알림 클릭 시 브라우저 창 즉시 포커스 복귀.

### [FR-05] 20kg 바벨 플레이트(원판) 최적 조합 계산기 (PlateCalculatorService)
- 목표 중량 입력 시 올림픽 규격 바벨(20kg/15kg/10kg)을 제외한 양쪽 원판 조합을 Greedy 알고리즘으로 최적화.
- 올림픽 규격 컬러(25kg 레드, 20kg 블루, 15kg 옐로우, 10kg 그린, 5kg 슬레이트, 2.5kg 차콜, 1.25kg 실버) 시각화.

### [FR-06] 스마트 점진적 과부하 추천 & RPE 피로도 분석 (ProgressionRecommendationService)
- 직전 세트 RPE(자각적 피로도) 및 과거 동일 종목 볼륨을 분석하여 다음 세트 [무게, 횟수, 쉬는 시간] 실시간 추천.
- RPE ≤ 7 (과부하 증량 +2.5kg), RPE 8 (페이스 유지), RPE 9.5~10 (피로 관리, 횟수 -1회 & 휴식 +30초).

### [FR-07] Web Audio API 무지연 사운드 효과음 (AudioAlertService)
- 세트 완료 챠임(D5-A5), 3초 전 카운트다운 틱(E5), 휴식 완료 알림(A5-C6-E6) 순수 Sine 파형 합성.

### [FR-08] 요일별 분할 루틴 플래너 & 루틴 빌더 (RoutineService)
- 월~일 7-Day 분할 스트립 및 TODAY 자동 감지.
- 4대 프리셋(4분할, 3분할 PPL, 2분할 상하체, 5분할 보디빌딩) 및 자유 커스텀 지원.

### [FR-09] GitHub 스타일 활동 잔디 히트맵 & 볼륨 델타 분석 (VolumeService)
- 16주간 날짜별 볼륨 기반 5단계 Calm Gradient 잔디.
- 직전 세션 대비 `+kg` 및 `+%` 점진적 과부하 달성률 듀얼 프로그레스 바.

### [FR-10] 인바디 맞춤 중량 추천기 (InBodyService)
- 체중, 골격근량, 체지방률, 경력 기반 FFMI 및 3대 운동(SBD) 웜업/본세트/스트렝스 권장표 제공.
