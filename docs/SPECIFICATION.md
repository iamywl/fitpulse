# FitPulse 서비스 기능명세서 (PRD & Technical Specification)

- **문서 버전**: v1.2.0 (요일별 분할 루틴 플래너 & 팬톤 볼트 프리미엄 디자인 시스템 탑재)
- **작성 일자**: 2026-09-08
- **대상 플랫폼**: Web MVP (스마트폰 기기 시뮬레이터 & 데스크톱 뷰 동시 지원) -> 향후 React Native 모바일 앱

## 1. 프로젝트 배경 및 기획 의도

### 1.1 핵심 문제의식
- **요일별 훈련 분할(Split Routine)의 부재**: 실제 웨이트 트레이닝 유저는 "월: 가슴/삼두, 화: 등/이두, 수: 하체, 목: 휴식..."과 같이 **요일별로 명확한 운동 분할 루틴**을 갖고 운동함. 기존 앱들은 이를 종합적으로 엮지 못함.
- **점진적 과부하 체감의 어려움**: 지난번 세션 대비 총 볼륨 증감률(+kg, +%) 피드백 부족.
- **인바디와 실전 중량의 괴리**: 체성분 측정 후 오늘 몇 kg으로 세트를 진행해야 할지 산출하기 번거로움.
- **시각적 완성도와 색상 대비**: 헬스장의 어두운 조명과 OLED 화면에서도 압도적인 시인성을 발휘하는 스포츠 컬러(Pantone 2288 C Volt) 필요.

## 3. 핵심 기능 요구사항 명세 (Functional Specifications)

### [FR-01] 요일별 분할 루틴 플래너 & 스케줄러 (Weekly Split Routine Planner)
- **7-Day Strip 바**: 월(가슴) · 화(등) · 수(하체) · 목(휴식) · 금(어깨) · 토(하체2) · 일(휴식).
- **오늘(TODAY) 자동 감지**: 시스템 날짜의 요일을 실시간 판별하여 형광 볼트 뱃지(`TODAY`)로 자동 포커싱.
- **분할 상세 정보**:
  - 부위별 타겟 근육 태그 (`#대흉근`, `#삼두근` 등)
  - 오늘 예정된 운동 종목 및 목표 중량/세트/횟수 가이드 (`4세트 × 8회 @ 75kg`)
  - 각 운동별 세트 수행 체크리스트 및 실시간 달성률(%) 프로그레스 바.
- **원클릭 연동**: "오늘 이 루틴으로 운동 시작하기" 클릭 시 해당 종목과 세트가 세팅된 오늘 운동 세션 자동 생성.

### [FR-02] 종목별 무게(kg) & 반복수(reps) 간편 기입기 (Exercise Set Manager)
- 종목 선택 (벤치프레스, 스쿼트, 데드리프트, OHP, 바벨로우 등).
- 세트별 무게 직접 입력 + 원터치 퀵 버튼 (`-2.5kg`, `+2.5kg`, `+5kg`).
- 세트별 반복수 직접 입력 + 원터치 스테퍼 (`-`, `+`).
- 세트 완료 체크 토글 (체크 시 즉시 종목 총 볼륨과 추정 1RM 실시간 계산).
- "오늘 운동 기록에 즉시 저장" 버튼 및 축하 파티클(Confetti) 연동.

### [FR-03] GitHub 스타일 잔디 히트맵 (Activity Heatmap)
- 16주간의 날짜별 운동량 및 볼륨 강도에 따른 4단계 색상 잔디 시각화.
- 오늘 날짜 원클릭 잔디 심기 시뮬레이션 지원.
- 마우스 호버 툴팁 및 클릭 시 세부 운동 내역 확인.

### [FR-04] 지난번 대비 총 볼륨 증감 비교 (Volume Delta Widget)
- 직전 동일 부위 루틴 대비 `+kg` 및 `+%` 점진적 과부하 달성률 듀얼 프로그레스 바.
- 종목별 세부 볼륨 증감 카드 리스트 (모바일 1열 전용 레이아웃 적용).

### [FR-05] 인바디 기반 맞춤 중량 추천기 (InBody Recommender)
- 체중, 골격근량, 체지방률, 경력 실시간 슬라이더 조절.
- 3대 운동 합산(SBD) 추정치 및 웜업/본세트/스트렝스 권장 중량표 제공.

### [FR-06] 모바일 시뮬레이터 (390px) & 데스크톱 뷰포트
- 스마트폰 기기 프레임 모드 및 데스크톱 와이드 모드 원클릭 토글.
- 모든 화면에서 텍스트 수직 찌그러짐 현상 완벽 방지.
