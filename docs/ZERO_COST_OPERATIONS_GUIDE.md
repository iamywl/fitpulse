## 💡 Executive Summary (한눈에 보는 결론)

FitPulse는 모든 비즈니스 로직(1RM, 볼륨 증감율, 바벨 플레이트 계산, 인바디 추천, RPE 추천 엔진)이 사용자의 기기(브라우저)에서 100% 연산되는 **순수 클라이언트 사이드 SPA(Single Page Application)**로 설계되었습니다.

따라서 **비싼 서버(EC2, 백엔드 VM)를 임대할 필요가 전혀 없으며**, 글로벌 CDN 호스팅 및 무료 PWA/네이티브 배포 방식을 활용하면 **MAU 100명은 물론 MAU 10,000명까지도 영구히 월 0원($0)**으로 쾌적하게 운영할 수 있습니다.

## 3. 아이폰 & 안드로이드 스토어 등록비 0원 해결책 (PWA)

애플 개발자 계정($99/년)과 구글 플레이 개발자 계정($25/평생) 비용을 들이지 않고, MAU 100명이 스마트폰에서 네이티브 앱처럼 사용하는 방법입니다.

```mermaid
flowchart LR
    A["FitPulse 배포 URL 접속<br>(카카오톡/인스타 링크)"] --> B{"스마트폰 기종 감지"}
    
    B -->|iPhone (Safari)| C["하단 [공유] 버튼 터치<br>-> [홈 화면에 추가] 클릭"]
    B -->|Android (Galaxy/Chrome)| D["하단 [앱 설치] 배너 터치<br>-> 즉시 다운로드 클릭"]
    
    C --> E["홈 화면에 FitPulse 앱 아이콘 생성!"]
    D --> E
    
    E --> F["주소창 없는 100% 풀스크린 네이티브 구동<br>오프라인 캐싱 & 햅틱 진동 & 알림 완벽 지원"]
```

### 3.1 아이폰 (iOS Safari)
- 링크 접속 후 Safari 하단 **[공유 아이콘(↑)]** -> **[홈 화면에 추가]** 클릭.
- **사용자 경험**: 사파리 주소창과 하단 툴바가 사라지고, **진짜 앱스토어에서 내려받은 앱처럼 100% 전체화면**으로 실행됩니다.
- 아이폰 바탕화면에 고해상도 FitPulse 앱 아이콘이 생성됩니다.

### 3.2 안드로이드 (Samsung Internet / Chrome)
- 웹 접속 시 브라우저 하단에 **"FitPulse를 홈 화면에 설치하시겠습니까?"** 배너 자동 노출.
- [설치] 버튼 1번만 누르면 구글 플레이스토어를 거치지 않고 **스마트폰 앱 서랍(Apps)에 정식 WebAPK 앱으로 자동 등록**됩니다.

### 3.3 안드로이드 전용 무료 APK 파일 직접 배포 (선택 사항)
- 원할 경우 GitHub Releases 또는 웹사이트 다운로드 버튼을 통해 `FitPulse.apk` 파일을 제공하여 수동 설치도 가능합니다 ($0).

## 5. 3분 원클릭 무료 배포 실전 가이드 (Netlify 기준)

현재 GitHub의 `iamywl/fitpulse` 저장소와 연동하여 3분 만에 무료 배포 URL을 발급받는 절차입니다.

1. **[Netlify (netlify.com)](https://www.netlify.com/) 회원가입** (GitHub 계정으로 1초 로그인).
2. **[Add new site] -> [Import an existing project]** 클릭.
3. **GitHub 선택 후 `iamywl/fitpulse` 저장소 지정**.
4. **빌드 설정 확인**:
   - Branch to deploy: `main`
   - Build command: `npm run build` (자동 감지됨)
   - Publish directory: `dist` (자동 감지됨)
5. **[Deploy site] 버튼 클릭**!
   - 1~2분 후 `https://fitpulse-xxxx.netlify.app` 고유 주소와 무료 SSL(자물쇠) 인증서가 자동 발급됩니다.
   - 사이트 설정(Site settings)에서 이름을 `https://fitpulse.netlify.app`과 같이 예쁘게 무료 변경할 수 있습니다.
