## 2. 결함 원인 정밀 진단

### 2.1 주간 분할 루틴 화면 글자 잘림 (WeeklySplitRoutineSection)
- **종목명 말줄임 (`스...`, `사..`, `벤...`)**:
  - 한 행(Row)에 체크박스, 순번(`01`), 운동명, 부위 뱃지, 세트/반복 뱃지(`4세트 × 6-8회회`), [기록하기] 버튼까지 5개 요소를 가로로 욱여넣음.
  - 430px 모바일 화면에서 우측 요소들이 270px 이상을 차지하여, 운동명 컨테이너가 40px 미만으로 압축되어 `truncate`에 의해 1글자만 남고 잘림.
- **반복수 중복 표기 (`6-8회회`)**:
  - `splitRoutineData.ts`의 `reps`가 이미 `'6-8회'`인데 렌더링 시 `${exercise.reps}회`로 중복 결합됨.
- **버튼 및 뱃지 세로 쪼개짐 (`루틴 설\n정`, `주간 분...`)**:
  - `TdsButton`과 `TdsBadge`에 `whitespace-nowrap flex-shrink-0`이 누락되어 flex 컨테이너에서 찌그러짐.
- **7-Day 스트립 `수 하...`**:
  - `truncate max-w-full`과 과도한 padding으로 인해 2글자 한글('하체')조차 45px 그리드 셀에서 잘림.

### 2.2 오늘 운동 완료 후 시각적 피드백 부재 (TodayWorkoutHeroSection)
- 운동 완료 저장 후에도 메인 화면 헤더는 여전히 "오늘 할 운동이에요"로 유지됨.
- 완료된 세션에 대한 축하 카드, 완료 뱃지, 총 볼륨 요약, 성장 분석 유도 액션이 부재하여 유저는 저장이 되었는지 체감할 수 없음.

### 2.3 샘플 데이터 히트맵 공백 & 신규 유저 빈 데이터 상태
- `mockData.ts`가 과거 28일 이내 11개 세션만 정의하여 16주(112일) 잔디의 80% 이상이 회색 빈칸으로 남아있었음.
- 빈 데이터(신규 유저) 상태에서 각 탭(잔디, 과부하, 분석)이 불친절하거나 공백으로 방치됨.

### 2.4 휴식 타이머 수정 불편 (RestTimerModal)
- 기존에는 `-15초`, `+15초`, `+30초` 버튼만 있어 원하는 휴식 시간(1분, 2분 등)을 설정하려면 여러 번 연타해야 함.

## 3. 서브에이전트별 해결 방안 및 설계 기준

### 3.1 `design_agent` (TDS Mobile 원칙 적용)
- **토스 리스트 아이템 구조 (BoardRow 방식)**:
  - 1행: 체크박스 + 순번 + **운동명 전체 (break-keep leading-snug, 절대 truncate 금지)** + [기록하기] 버튼
  - 2행: 부위 뱃지 + `4세트 · 6~8회` + `권장 휴식 2분`
- **7-Day 요일 탭**:
  - `whitespace-nowrap text-[10px] font-bold text-center` 적용, 2글자 부위명('가슴', '등', '하체', '어깨', '팔', '휴식') 완전 노출.
- **오늘 운동 완료 HUD**:
  - 완료 시 헤더 텍스트: "오늘 운동을 멋지게 완료했어요! 🎉"
  - `TdsBadge`: "오늘 운동 완료" (Green)
  - 4개 요약 통계 카드: 들어올린 볼륨(kg), 완주 종목 수, 총 세트 수, 소요 시간
  - 액션: [성장 분석(잔디) 보러가기 📈], [기록 수정하기]
- **타이머 프리셋 칩**:
  - 원터치 퀵 칩: `[30초]`, `[1분]`, `[1분 30초]`, `[2분]`, `[3분]`

### 3.2 `qa_agent` (품질 및 무결성 검증)
- `mockData.ts`: 16주(112일)간 주 3~4회, 총 48~52개 세션의 점진적 과부하 데이터 생성 (레벨 1~4 단계적 볼륨 분포).
- 신규 유저(0개 운동) 빈 데이터 상태에서 런타임 오류 0건, 친절한 Toss 안내 카드 및 [샘플 데이터 불러오기] 버튼 동작 확인.
- `TdsButton`, `TdsBadge`에 `whitespace-nowrap flex-shrink-0` 적용 후 컴파일 무결성 보장.
